Architecture Principles

Why it's designed this way

Six load-bearing design invariants that shape every agent interaction in the pipeline.

⊕
Adversarial decorrelation
Every parallel voting pair intentionally crosses model families — Anthropic (haiku/opus) paired with OpenAI (gpt-mini/gpt-5.1). A shared family bias cannot simultaneously corrupt both votes, raising agreement signal quality.
never: two same-family models in parallel
⬆
Escalation-first cost control
The cheapest capable model always runs first. More expensive models are invoked only when the cheaper rung fails to reach consensus. The vast majority of rows resolve at the first rung (haiku + gpt-mini).
cost = f(disagreement rate), not input size
⊘
Code-exclusive blocking authority
No model can block an entity from the output plan. Only resolveCitationsDeterministic() holds BLOCKING authority — three deterministic checks against fp.cells. All LLM validator findings are WARN-only.
BLOCKING ≡ code · WARN ≡ LLM
≡
Conservation law (CE3)
Every cell entering the pipeline must appear in the output. proposed = accepted + unresolved is enforced at Stage 7. Cells can be accepted, blocked-to-unresolved, or NOISE-classified — but none can vanish silently.
proposed = accepted + unresolved (S7)
⚡
Import always wins
The cost guard enforces a $25/hr rolling ceiling. Import runs under the IMPORT_CONTEXT exemption — never denied, never degraded — but all spend is metered and telemetry is never bypassed.
noCap ≠ unmetered — telemetry always flows
↻
Extraction cache (sha256-keyed)
Every Stage 4 AI call is keyed by sha256(deployment+promptVer+system+user). An LRU in-process cache + Azure Blob persistence means a re-import of an identical artifact costs zero AI spend.
identical input → same output, zero cost

System Invariants

The four stability guarantees

These properties hold for every import run. Breaking any one is a bug, not a trade-off.

Conservation
proposed = accepted + unresolved
Every cell entering the pipeline appears in exactly one output bucket. No silent drops, no phantom entities. Enforced at Stage 7.
unresolved = proposed − accepted
Citations
BLOCKING on three citation failures
Code holds exclusive blocking authority. Three BLOCKING types: invalid-citation-pointer, fabricated-strict-id, unresolvable-relation-target.
blocked=true → unresolved[] (never discarded)
Cost Guard
$25/hr ceiling · IMPORT_CONTEXT exempt
1-hour rolling window, $25 ceiling. Import runs under IMPORT_CONTEXT exemption — never denied, never degraded — but telemetry always flows.
IMPORT_CONTEXT = noCap (not unmetered)
Output
UnifiedProposalBundle schema
Stage 7 produces a single typed output: plan, unresolved[], provenance[], counts, completeness classification, ensembleDisagreements[].
completeness: COMPLETE|PARTIAL|PARTIAL_NO_BACKBONE|EMPTY
